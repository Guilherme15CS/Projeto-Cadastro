# 📋 Sistema de Cadastro de Pessoas

Aplicação web desenvolvida em **Python** com **Streamlit**, criada para gerenciar o cadastro de pessoas de forma simples e intuitiva. O projeto foi construído como exercício prático de integração entre uma interface web e um banco de dados relacional.

## 🚀 Funcionalidades

- **Visualizar** todos os registros cadastrados em formato de tabela
- **Adicionar** novas pessoas ao banco de dados
- **Editar** informações de registros existentes
- **Excluir** registros do cadastro

## 🗂️ Dados Cadastrados

Cada pessoa é registrada com os seguintes atributos:

- CPF
- Nome
- Sexo
- Data de Nascimento
- Situação Civil
- Estado Civil
- Cidade que Mora
- Time que Torce

## 🛠️ Tecnologias Utilizadas

- **Python** — lógica da aplicação
- **Streamlit** — construção da interface web
- **MySQL** — armazenamento e persistência dos dados

## ⚠️ Observação

Este projeto tem finalidade **didática/fictícia**, servindo como demonstração de integração entre Python, Streamlit e MySQL. Por esse motivo, não possui validações de dados de entrada (como formatação de CPF ou datas).
